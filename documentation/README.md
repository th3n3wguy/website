# Contributor documentation

This directory contains tracked, durable guidance distilled from completed work,
not task transcripts. Start here alongside
[repository instructions](../.github/copilot-instructions.md).

- [Architecture and invariants](architecture.md): source map, stack, design,
  content, metadata, and browser behavior.
- [Agent workflow](agent-workflow.md): roles, local plans, delegation, and the
  mandatory pre-push documentation review.
- [Operations](operations.md): development, validation, builds, and release.
- [Medium migration inventory](../docs/medium-migration.md): historical import
  provenance and recovered assets. Kept at its existing path; new contributor
  documentation belongs here.

The root [README](../README.md) is the user-facing setup and publishing entry.
`.plans/` is ignored local working state and is not part of this documentation.
